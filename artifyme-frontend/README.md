# Artify frontend (React + Vite)

Customer app for portrait sketch orders. Talks to the Go API at `VITE_API_URL`.

## Setup

```bash
cd artifyme-frontend
npm install
cp env.example .env
npm run dev
```

Open http://localhost:5173

## Scripts

- `npm run dev` — Vite dev server
- `npm run build` — production bundle
- `npm run preview` — preview production build
